# Wiki — feature list

## Layout (CommandAPI-docs style)

- [ ] Top bar: brand, section links, search field with K hint,
  appearance toggle, version pill
- [ ] Collapsible grouped sidebar with active-page highlight
- [ ] Documentation-width article column + breadcrumbs
- [ ] Sticky side per-page index ("On this page") with scroll-spy,
  listing the current page's sections (desktop only)
- [ ] Hover `#` anchors on every section heading (deep-linkable)
- [ ] Previous / next page footer
- [ ] Mobile: sidebar becomes a drawer, outline drops away

## Search & theme

- [ ] Top-bar search filters sidebar and pages as you type
- [ ] Ctrl+K / Cmd+K command palette over pages + section headings
- [ ] Light + dark themes, OS preference by default, toggle wins
  for the session

## Reading mode (Nolebase Enhanced Readabilities, as on CommandAPI)

- [ ] Spotlight: dims the page except the hovered block, on/off toggle
- [ ] Spotlight styles: underline highlight vs side-marker highlight
- [ ] Layout switch: full-width / sidebar-adjustable / both-adjustable
- [ ] Page and content max-width sliders
- [ ] Reading mode controls live in a top-bar menu; desktop only,
  hidden on small screens

## Article content

- [ ] Tip and Note/Warning callouts, visually distinct
- [ ] Monospace command / config blocks, copy-pasteable
- [ ] Shared section URLs scroll to and highlight the heading

## Content & data

- [ ] Six guides: Installation, Post-install tuning, Server hosting,
  Troubleshooting, FAQ, Hardware compatibility (simplified from
  Fabulously Optimized; upstream docs stay outbound links)
- [ ] One Markdown file per guide; sidebar, outline, search index,
  and prev/next generated from the tree
- [ ] No per-version forks; version differences noted inline
- [ ] Broken internal links fail the build
