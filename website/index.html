Supported

Four things cost you frames.

Zitrus goes after each one, then ships the config that makes the change stick. Every setting listed here is already tuned in the pack.

01

Rendering

Sodium rebuilds the chunk renderer, so a higher render distance stops being a slideshow. Culling mods drop entities and faces you cannot see.

Sodium Entity Culling Cull Fewer Leaves ImmediatelyFast
02

Frame pacing

Steady frame times beat a high average. HUD updates spread across frames, input polls move off the main thread, and an unfocused window drops to 10 FPS.

Gnetum Ixeris Dynamic FPS
03

Memory and load

Smaller block state models, less loaded at startup and fewer allocations per tick. The difference shows up in load times and in long sessions.

FerriteCore ModernFix Jasione Put A Plug In it!
04

Server tick rate

Game logic is optimised and chunk work moves off the main thread, so the network stays out of your tick budget. Vanilla clients still join.

Lithium CCME Krypton ServerCore

Getting started

Up and playing in a couple of minutes.

Read Sodium's driver notes first

A black screen or crash on launch is almost always a driver Sodium flags. Disabling the one it names fixes most reports before anything else is tried.

Install the pack for your version

Grab it from Modrinth through any launcher: Modrinth App, Prism, ATLauncher or MultiMC. Adding more mods afterwards is the intended workflow, not a workaround.

Give it enough memory

Render distance is the first thing to raise when FPS feels low, but only after the launcher is pointed at your dedicated GPU and RAM is not the limit. The post-install guide has the numbers per setup.

Server, mrpack-install 
mrpack-install zitrus [version]
Server, mcman 
mcman init --mrpack mr:zitrus
Any host, pre-launch command 
java -jar packwiz-installer-bootstrap.jar -g -s server https://…/pack.toml
It stays a foundation, not a walled garden. Remove what you don't want, add what you do.

Zitrus is tuned as a set, so mods that replace the same work, another renderer or another minimap, will fight it. Drop one or the other and the pack stays fast.
