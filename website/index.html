Zitrus is tuned as a set, so mods that replace the same work, another renderer or another minimap, will fight it. Drop one or the other and the pack stays fast. The wiki covers which mods are worth adding on top and which ones are not.

Everything in the box.

Every curated mod Zitrus ships, grouped by what it does for you. Libraries are left out because they exist only to make the rest work. The set shifts slightly between Minecraft versions.

Black screen or crash on launch?

It is almost always a driver Sodium flags. Read Sodium's driver notes and disable the one it names, which fixes most reports before anything else is tried.

Low FPS after the first minute?

Raise render distance, make sure the launcher runs the game on your dedicated GPU, and give it enough RAM. The post-install guide has the numbers per setup.

Running a server instead?

Server setup, Docker and pre-launch commands are in the server section of the repo. Vanilla clients still join.
